# Rudra Raj Portfolio

## Files
- `index.html` — main portfolio page
- `style.css` — complete responsive styling

## How to run
1. Keep `index.html` and `style.css` in the same folder.
2. Double-click `index.html` or open it in Chrome/Edge.
3. Replace the placeholder email and social links in `index.html`.
4. The profile photo is included in `assets/profile.jpg` and is displayed in the hero section.

## Sections
Home, About, Skills, Projects, Certifications & Learning, Contact.

The website is responsive and includes a mobile navigation menu.
